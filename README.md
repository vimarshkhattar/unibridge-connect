# UniBridge Connect

I already have an existing project called UniBridge. I want you to create a redesigned frontend/UI for my existing application.

IMPORTANT: Do NOT change the idea of my application and do NOT invent a completely different product.

UniBridge is a platform designed to help university students, especially international students, connect with other students, discover campus resources and events, get useful guides, and use an AI assistant.

My existing application already contains these pages/features:

Landing page

Sign in

Sign up

Onboarding

Dashboard

Discover students

Connections

Events

Guides

AI Assistant

Profile

Settings

I already have a working backend, authentication, database, APIs and Supabase integration in my original project.

For now, I ONLY want you to create a much better frontend design.

Design Goal

Make UniBridge look like a polished, modern startup/product that I could confidently show on my resume and to internship recruiters.

The design should feel:

Modern

Clean

Premium

Student-friendly

Professional

Minimal but not boring

Easy to navigate

Responsive on desktop, tablet and mobile

Use a consistent design system throughout the whole application.

Visual Style

Use a modern SaaS-style interface.

Clean white/light backgrounds

Modern blue/purple accent colors

Subtle gradients where appropriate

Rounded cards

Clean modern typography

Professional icons

Good spacing and hierarchy

Small tasteful animations

Modern buttons

Modern form inputs

Beautiful empty states

Responsive layouts

Avoid making the application overly colorful or childish.

Important Technical Instruction

This is primarily a frontend/UI prototype.

Do NOT spend time rebuilding my backend.

Do NOT create a completely different database architecture.

Do NOT redesign UniBridge into another type of social network.

Use realistic mock data only where necessary to demonstrate the frontend.

The purpose of this Lovable project is to create a beautiful frontend that I will later integrate into my existing Next.js + TypeScript + Supabase UniBridge project.

Focus heavily on UI quality, UX, responsiveness, component consistency, and professional visual design.

Build the entire interface so that all pages share the same design language.
